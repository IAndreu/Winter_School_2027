# Día 2

Materiales de las sesiones del día 2 de la Escuela de Invierno 2027.

Cada ponente tiene su propia subcarpeta aquí, con el formato
`apellido-tema/` (minúsculas, guiones, sin acentos). Por ejemplo:

```
day2/
  apellido-tema/
    README.md
    slides/
    practicas/
    datos/
```

Para añadir material, consulta la [guía para el profesorado](../../CONTRIBUTING.md)
y parte de la [plantilla de ponente](../_plantilla-ponente/README.md).

Las tareas evaluables, los foros y los datos de gran tamaño no van aquí, sino
en el Aula Virtual (Moodle).
